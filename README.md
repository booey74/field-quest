# Field Quest v1.8.1

Patch revision of the v1.8 boundary-setup UX release.

- Walk Boundary now requires explicit confirmation, matching Draw/Edit Boundary.
- Walk flow: Start GPS → mark 3+ points → Confirm boundary → Generate/save becomes available.
- Any further boundary change clears confirmation and requires reconfirmation.
- Expanded Walk mode also includes Confirm boundary.
- Draw/Edit behaviour remains unchanged.
- Saved areas and Easy/Medium/Hard gameplay remain unchanged.
- Service-worker cache updated to v1.8.1.
