# Field Quest v1.8.2

Patch revision of the v1.8 boundary-setup UX release.

## Expanded Walk-mode layout refinement
- Start GPS and Mark boundary point now sit side-by-side.
- Confirm boundary sits on its own full-width row below them.
- Once GPS is active, Start GPS changes to GPS active and is disabled/de-emphasised.
- This gives a clearer visual sequence:
  Start GPS → mark points → Confirm boundary.

## Behaviour unchanged
- Walk Boundary still requires explicit confirmation.
- Draw/Edit Boundary behaviour is unchanged.
- Saved areas and gameplay are unchanged.
- Service-worker cache updated to v1.8.2.
